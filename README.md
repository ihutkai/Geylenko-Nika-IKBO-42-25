# Эмулятор оболочки — вариант 6

Учебный проект на Python и Tkinter. Реализованы этапы 1 (REPL) и 2
(конфигурация). Этап 3 (JSON VFS) будет добавлен следующим шагом.
Этапы 4 и 5 не входят в выбранный объём работы.

## Запуск

Нужен Python 3.11 или новее с Tkinter. Сторонние пакеты не требуются.
Из папки проекта:

```console
python src/main.py
```

В Windows также можно запустить `run.bat`. Проверка Tkinter:
`python -m tkinter`.

## Команды и настройки

- `ls [путь]`: заглушка, печатает своё имя и список аргументов.
- `cd [путь]`: заглушка, печатает своё имя и список аргументов.
- `exit`: закрывает приложение; аргументы запрещены.
- Пустой ввод не выполняет команд.
- Неизвестные команды и лишние аргументы выводят сообщение об ошибке.

Парсер использует `str.split()`: повторные пробелы игнорируются.
Кавычки, пути с пробелами, флаги и конвейеры пока не поддерживаются.
`ls` и `cd` принимают не более одного аргумента пути.
Имя VFS для заголовка пока задано как `demo-vfs`; файл VFS не загружается.

## Устройство

- `src/shell.py`: `CommandResult` хранит результат команды;
  `execute()` разбирает строку и выполняет команды.
- `src/main.py`: `ShellWindow` создаёт окно; `write()` добавляет вывод;
  `submit()` обрабатывает Enter; `main()` запускает цикл событий.
- `tests/test_shell.py`: автоматические проверки команд и ошибок.

## Проверка

```console
python -m unittest discover -s tests -v
```

Для интерактивной демонстрации введите по очереди:

```text
ls
ls /home
cd
cd /home/user
ls a b
cd a b
unknown
exit argument
exit
```

Также проверьте пустую строку и ввод `  ls   /home  `.
Последняя команда `exit` должна закрыть окно.

Каждый этап задания нужно сохранить отдельным коммитом в публичном
репозитории. Этот проект пока не опубликован.

## Этап 2: конфигурация и стартовый скрипт

Запускать следующие команды нужно в терминале из папки проекта:

```console
python src/main.py --config config.toml
python src/main.py --vfs examples/custom.json --startup examples/startup.txt
python src/main.py --config config.toml --vfs examples/override.json
```

`--config` задаёт TOML-файл с ключами `vfs_path` и `startup_script`.
`--vfs` и `--startup` переопределяют соответствующие значения TOML.
Без параметров используются имя `demo-vfs` и интерактивный режим.
Файл конфигурации читается только при явном указании `--config`.
Все относительные пути считаются от текущей рабочей папки терминала.
Итоговые настройки выводятся в терминал и окно эмулятора.
Имя файла VFS отображается в заголовке, но загрузки JSON на этапе 2 нет.

`load_settings()` в `src/config.py` разбирает аргументы и проверяет TOML;
при ошибке выводит сообщение в терминал и завершает запуск с кодом 2.
`run_startup()` в `src/startup.py` читает UTF-8 скрипт и показывает команды
и результаты в GUI. Пустые строки и комментарии после `#` пропускаются.
После ошибки команды выводится номер строки, выполнение продолжается.
При ошибке чтения скрипта окно остаётся доступным для ручного ввода.
Команда `exit` завершает скрипт и закрывает окно.

Демонстрации для Windows: `scripts/check_parameters.bat` и
`scripts/check_errors.bat`. Каждый файл проверяет все параметры запуска.
Закрывайте очередное окно, чтобы перейти к следующему примеру.
Примеры включают приоритет CLI, ошибки чтения и синтаксиса TOML,
отсутствующий скрипт, ошибки команд, комментарии и выход из скрипта.
